## Acerca del repositorio

Aquí reúno mis ejercicios de **COBOL**, desde operaciones básicas hasta manejo de archivos y procesamiento por lotes. Utilizo **GnuCOBOL** para compilar y **OpenCobolIDE** como entorno de desarrollo.

## Contenido

| Área | Temas |
| :--- | :--- |
| **Fundamentos** | Estructura del programa, variables y tipos de datos |
| **Lógica** | Condiciones, ciclos y operaciones aritméticas |
| **Datos** | Importes, cadenas de texto y fechas |
| **Tablas** | Recorridos, búsquedas y ordenación |
| **Archivos** | Lectura y escritura de archivos secuenciales e indexados |
| **Modularidad** | Subprogramas y copybooks |
| **Procesos** | Lotes, validaciones y reportes |
